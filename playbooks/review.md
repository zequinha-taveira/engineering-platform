# Review Playbook

> Guia para code review na Engineering Platform.

## Checklist

### Estrutura
- [ ] Código segue padrões em `standards/coding.md`
- [ ] Funções com responsabilidade única
- [ ] Nomes descritivos

### Testes
- [ ] Testes unitários para novos códigos
- [ ] Testes de integração para fluxos
- [ ] Cobertura mínima 80%

### Segurança
- [ ] Input validado
- [ ] Secrets não expostos
- [ ] Autenticação verificada se aplicável

## Fluxo

1. Revisor lê especificação
2. Revisor analisa código
3. Revisor comenta problemas
4. Autor corrige
5. Revisor aprova
