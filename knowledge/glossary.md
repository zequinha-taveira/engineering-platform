# Glossário

> Terminologia do domínio da Engineering Platform.

## Termos Gerais

### Engineering Platform
Plataforma aberta para engenharia de software assistida por IA, baseada em padrões, agentes, MCP e automação.

### AI Agent
Programa autônomo que executa tarefas específicas usando IA, com responsabilidades e contexto definidos.

### MCP (Model Context Protocol)
Protocolo para comunicação entre agentes de IA e ferramentas, fornecendo contexto e capacidades.

### PREVC
Workflow de 5 fases: **P**lanning → **R**eview → **E**xecution → **V**erify → **C**omplete.

## Arquitetura

### Constitution
Documento que define a identidade técnica do projeto, incluindo princípios, governança e requisitos.

### Standards
Padrões técnicos que devem ser seguidos em todo o projeto (código, APIs, testes, segurança).

### Specification
Documento que descreve uma funcionalidade em detalhe, incluindo requisitos, fluxos e cenários de teste.

### Contract
Acordo sobre interfaces, responsabilidades e restrições de um módulo.

### ADR (Architecture Decision Record)
Registro de decisão de arquitetura significativa, incluindo contexto, opções consideradas e consequências.

## Componentes

### Prompt System
Sistema de templates e geração de prompts profissionais para tarefas de engenharia.

### Agent Catalog
Catálogo de agentes de IA especializados, com responsabilidades, templates e processos definidos.

### Knowledge Base
Base de conhecimento compartilhada com padrões, decisões, glossário e lições aprendidas.

### MCP Server
Servidor que implementa o Model Context Protocol, fornecendo recursos e ferramentas para agentes.

## Processos

### Code Review
Revisão de código por outro desenvolvedor ou agente para garantir qualidade, segurança e aderência a padrões.

### Handoff
Transferência de responsabilidade entre agentes ou fases, com artefatos e contexto.

### Orchestration
Coordenação de múltiplos agentes para completar uma tarefa complexa.

## Métricas

### Coverage
Porcentagem de código coberta por testes.

### Latency
Tempo de resposta de uma operação.

### Throughput
Quantidade de operações por unidade de tempo.

## Segurança

### Authentication
Processo de verificar identidade de um usuário ou sistema.

### Authorization
Processo de verificar se um usuário ou sistema tem permissão para executar uma ação.

### RBAC (Role-Based Access Control)
Controle de acesso baseado em funções/perfis.

### Rate Limiting
Limitação da quantidade de requisições por período de tempo.

## Ferramentas

### CI/CD
Integração Contínua e Entrega Contínua — processos automatizados de build, teste e deploy.

### Container
Empacotamento de aplicação com suas dependências (Docker).

### Infrastructure as Code
Gerenciamento de infraestrutura através de código versionado (Terraform, Ansible).
