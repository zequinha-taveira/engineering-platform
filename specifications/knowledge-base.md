# Specification: Knowledge Base

> Base de conhecimento compartilhada entre humanos e agentes de IA.

## Purpose

Centralizar padrões, decisões, glossário e lições aprendidas para garantir consistência em todo o projeto.

## Structure

```
knowledge/
├── README.md
├── glossary.md
├── patterns/
│   ├── solid.md
│   └── repository-pattern.md
└── decisions/
    └── 001-typescript.md
```

## Content Types

| Type | Description | Examples |
|------|-------------|----------|
| Patterns | Design patterns | SOLID, Repository |
| Decisions | ADRs | TypeScript choice |
| Glossary | Domain terms | Definitions |
| Playbooks | Operational guides | How-to guides |

## Usage

- Humans: Read and contribute
- AI Agents: Consult before acting
- Both: Single source of truth
